Vinea 🍇

v0.3.0

Should I irrigate? Can I spray? — a daily, grower-facing advisory for tomorrow, produced overnight from hourly vineyard weather.

The one design constraint. Every number is computed in plain Python. The model judges and explains; it never calculates. That is why an advisory cannot contain a hallucinated quantity — and why a prompt injection cannot change a value it cannot reach.

What you are looking at

Real hourly weather for two real Greek wine regions, run through the real pipeline: a FAO-56 water balance and a four-gate spray-window analysis, one advisory per night. The numbers above were produced by features.py — the same code path the nightly batch runs — and frozen into a JSON file this page reads. Nothing is computed in your browser; it renders numbers, it does not produce them.

Two honest labels. This is a replay, not a live service: GitHub Pages serves files, and the system's Postgres, queue, API and worker are not running behind it. And every advisory here is deterministic — degraded=true, no model was called, so the prose is templated rather than written. The physics is identical either way; what an LLM adds is the judgement on borderline nights and language a grower can act on.

Checkable by hand

Open “Check the arithmetic” on any card. ET₀ × Kc, minus effective rain, clamped to [0, TAW]. If the total disagrees with the headline, the headline is wrong.

Missing stays missing

Empty and non-finite cells become None, are counted, and lower confidence — never zero-filled. The confidence figure is that penalty, not a vibe.

Two sites, one codebase

Nemea and Naoussa get different answers because their weather differs, not because anything was special-cased. Per-tenant weather is enforced end to end.

What is behind it

Beyond the advisory: Postgres row-level security so a forgotten WHERE returns nothing rather than everything; SLOs defined and measured in SQL with an error budget written before the first breach; hashed, revocable API keys with an access log; a Helm chart whose migration hook must succeed before any new pod serves traffic; self-hosted tracing where the deterministic node visibly has no model call beneath it; and retrieval over FAO-56 gated on a labelled question set. Twelve architecture decision records say why — including the one that deletes a feature the measurements did not support.
